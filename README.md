## Sobre mim

Sou um Desenvolvedor Backend com foco na construção de APIs RESTful escaláveis, processamento de dados em produção e otimização de banco de dados. Atualmente, trabalho na sustentação e evolução de sistemas críticos, lidando diretamente com regras de negócio, integrações complexas via pipelines de ETL/ELT e melhoria de performance de consultas SQL. Gosto de resolver problemas com Python, garantindo arquiteturas limpas, código testável e boa documentação.
