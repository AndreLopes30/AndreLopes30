## 👨‍💻 Sobre mim

Sou desenvolvedor backend com foco atual em **Java e Spring Boot**, construindo APIs REST com arquitetura em camadas, autenticação, persistência de dados e testes automatizados.

Também possuo experiência prática com **Python**, principalmente no desenvolvimento de APIs, integrações entre sistemas, automações e otimização de consultas em bancos relacionais.

Além das minhas stacks principais, busco ampliar minha capacidade de adaptação entre diferentes ecossistemas backend. Nesse processo, desenvolvi também uma API completa em **C# e ASP.NET Core**, utilizando Entity Framework Core, PostgreSQL, Docker, migrations e Testcontainers.

Nos meus projetos, venho aplicando:

- arquitetura com Controller, Service e camada de persistência;
- APIs REST e integração entre sistemas;
- autenticação e autorização com JWT;
- modelagem e otimização de bancos relacionais;
- migrations e versionamento de schema;
- testes unitários, testes HTTP e testes de integração;
- Docker e pipelines de CI/CD;
- documentação técnica com OpenAPI;
- deploy e infraestrutura em AWS.

## 🚀 Projetos em destaque

### 🏫 [Escola API](https://github.com/AndreLopes30/escola-api)

API REST de gerenciamento escolar desenvolvida para aprofundamento em **Java e Spring Boot**.

**Stack:** Java 21 · Spring Boot · Spring Security · Spring Data JPA · Hibernate · PostgreSQL · Docker · JUnit · Mockito · MockMvc · Testcontainers

**Principais recursos:**

- arquitetura em camadas com Controller, Service e Repository;
- autenticação stateless com JWT;
- validação de dados com Bean Validation;
- persistência com Spring Data JPA e Hibernate;
- testes unitários com JUnit 5 e Mockito;
- testes da camada web com MockMvc;
- testes de integração com PostgreSQL real e Testcontainers;
- documentação dos endpoints com OpenAPI.

---

### 🎫 [TicketFlow API](https://github.com/AndreLopes30/ticketflow-api)

API REST para gerenciamento de chamados de suporte, construída em **C# e ASP.NET Core** como projeto de exploração do ecossistema .NET e demonstração de versatilidade em desenvolvimento backend.

**Stack:** C# · .NET 10 · ASP.NET Core · Entity Framework Core · PostgreSQL · Docker · xUnit · Testcontainers · OpenAPI

**Principais recursos:**

- arquitetura com Controllers, Services, DTOs e DbContext;
- criação, consulta, atualização e exclusão de chamados;
- filtros e paginação;
- operações assíncronas;
- regras de transição entre status;
- tratamento global de exceções com Problem Details;
- migrations com Entity Framework Core;
- PostgreSQL executado com Docker Compose;
- testes HTTP com provider InMemory;
- testes de integração com PostgreSQL real e Testcontainers;
- validação de migrations, constraints e persistência real.
